# CLIVIA 站点布局改进方案（对标 CSDN）

> 生成时间：2026-09-20
> 站点：https://jiashiqi-thinkdifferent.github.io/
> 技术底座：Hexo 8.1.2 + NexT 8.29（Gemini）+ GitHub Pages 双分支
> 现状资产：11 只个股页 + 11 个三好报告页 + 3 类文章 + 股票估值数据库（PostgreSQL）

---

## 一、诊断：CLIVIA 与 CSDN 的差距

| 维度 | CSDN | CLIVIA 现状 | 差距 | 说明 |
| --- | --- | --- | --- | --- |
| 顶部导航 | 常驻吸顶条：Logo + 搜索框 + 频道导航 + 创作入口 | 只有 NexT 品牌横幅（深墨绿大标题 + 菜单），滚动后消失；无搜索入口 | 大 | 站内 11 只个股、11 份报告全靠左栏菜单或分类页才能到达 |
| 主体栏数 | 三栏：左导航 / 中信息流 / 右推荐位 | 左栏 + 内容两栏；全宽改造后右侧大片留白 | 大 | 1200px 以上屏幕右侧约 300px 完全空置 |
| 卡片信息密度 | 标题 + 两行摘要 + 作者 + 阅读 + 点赞 + 收藏 + 标签 + 缩略图 | 标题 + 200 字摘要 + 日期（刚做完自动摘要） | 中 | 摘要偏长，缺分类标签、字数/阅读时长、封面 |
| 内容分栏 | 频道 Tab（推荐 / 关注 / 热榜）+ 各板块「更多」 | 单一时间倒序流 | 中 | 投资笔记、个股研究、读书笔记混在一条流里 |
| 数据位 | 热榜、活动日历、课程推荐占据右栏 | 有估值数据库 + 三好评分，但只在个股页/报告页，首页零入口 | 大 | **本站最大优势没有上首页**，这是最该补的一块 |
| 文章页 | 左操作条 + 右固定目录 + 底部相关推荐 | TOC 在侧栏，无相关推荐 | 中 | 读书笔记 9000 字长文尤其需要右侧固定目录 |
| 移动端 | 单列 + 底部 Tab | NexT 响应式单列，无底栏 | 小 | 可后补 |

**一句话结论**：CLIVIA 的内容资产（估值数据、三好评分）比 CSDN 首页的推荐位更有价值，但被埋在二级页面；CSDN 真正值得抄的是「常驻导航 + 三栏 + 高密度卡片 + 右侧数据位」这套骨架，把本站的数据资产摆到首页右侧。

## 二、目标布局

宽屏（≥1200px）三栏 + 吸顶导航条：

- **顶部吸顶条**（新增）：CLIVIA Logo + 搜索框 + 主导航（首页 / 个股研究▾ / 三好评分 / 分类 / 标签 / 归档）。滚动时品牌横幅收窄为导航条，不再随页面滚走。
- **左栏**（已有，微调）：首页 / 个股研究 / 三好评分 / 分类·标签 / 关于，保留折叠把手与独立滚动。
- **中栏**：内容流，顶部加频道 Tab（全部 / 投资笔记 / 个股研究 / 读书笔记），卡片改为「标题 + 2 行摘要 + 元信息行 + 右侧缩略图」。
- **右栏**（新增）：股票池速览、三好评分榜、标签云·归档，≥1200px 显示，992–1199px 自动隐藏降级为两栏。

## 三、改造清单

优先级：**P0 骨架与信息密度 → P1 内容可达性 → P2 互动与移动端**。全部改动走「注入点 + 样式覆盖 + 自建脚本」，**不修改 `themes/next/` 下任何模板**（主题升级会被覆盖，这是本站已有约定）。

### P0-1 顶部吸顶导航条（改动量：中）

- 做法：`_config.next.yml` 的 `custom_file_path` 增加 `header: source/_data/header.njk`，写入品牌链接 + 导航项 + 个股下拉菜单 + 搜索框；`styles.styl` 让 `header.header` 吸顶并在滚动后收窄。
- 涉及文件：`_config.next.yml`、`source/_data/header.njk`（新建）、`source/_data/styles.styl`。
- 要点：
  - 导航条高度控制在 56px，吸顶后品牌横幅的高度过渡用 `.header--compact` 类切换（JS 监听 `scroll`，节流 100ms）。
  - 「个股研究」做成下拉，11 只股票从 `/stocks/data/overview.json`（见 P1-2）动态生成，新增股票不用改导航。
  - 与现有左栏折叠共存：导航条负责「跨栏目跳转」，左栏负责「当前栏目内的次级导航」。

```styl
header.header {
  position: sticky;
  top: 0;
  z-index: 1000;
}
.header--compact .site-title { font-size: 1.4rem; }
.header--compact .site-subtitle { display: none; }
```

### P0-2 首页右侧数据栏（改动量：大，收益最大）

- 做法：新建 `source/js/home-aside.js`，在首页把三个模块插进 `.content-wrap` 末尾，再用 CSS Grid 把内容流与右栏并排。
- 涉及文件：`source/js/home-aside.js`（新建）、`source/_data/body-end.njk`（按需加载）、`source/_data/styles.styl`。
- 三个模块：
  1. **股票池速览**：股票数量、数据更新日期、估值分位最低/最高的各 3 只（点进对应个股页）。
  2. **三好评分榜**：读已有 `/three-good/data/scores.json`，取最新一期综合分 TOP5。
  3. **标签云 · 归档**：标签云 + 最近 6 个月归档入口。
- 数据来源：`scores.json` 现成可用；股票速览需新增 `source/stocks/data/overview.json`（见 P1-2）。

```styl
@media (min-width: 1200px) {
  .content-wrap {
    display: grid;
    grid-template-columns: minmax(0, 1fr) 300px;
    gap: 20px;
    align-items: start;
  }
  .clivia-home-aside { position: sticky; top: 72px; }
}
@media (max-width: 1199px) {
  .clivia-home-aside { display: none; }
}
```

- 注意：右栏由 JS 注入，无 JS / 爬虫看到的是原始两栏（内容是辅助信息，可接受）；页脚宽度已由全宽改造统一，需同步确认右栏不溢出。

### P0-3 卡片信息密度（改动量：中）

- 做法：
  1. `_config.next.yml` 的 `post_meta` 打开 `tags: true`，卡片补上标签。
  2. 新建 `source/js/post-meta-extra.js`，按 `.post-body` 文本长度算字数与「约 N 分钟读完」，追加到元信息行。
  3. 首页摘要从 200 字收紧到约 110–120 字（`scripts/auto-excerpt.js` 的 `LIMIT` 改为 110），配合 CSS 两行省略，视觉更接近 CSDN 的紧凑卡片。
  4. 支持 front-matter `cover:` 字段，有封面时卡片右侧显示缩略图（无封面则不占位，避免空洞）。
- 涉及文件：`_config.next.yml`、`scripts/auto-excerpt.js`、`source/js/post-meta-extra.js`（新建）、`source/_data/styles.styl`。

### P0-4 首页频道 Tab（改动量：小）

- 做法：新建 `source/js/home-tabs.js`，给每张卡片标记 `data-cats`（取文章 categories），顶部注入「全部 / 投资笔记 / 个股研究 / 读书笔记 / 技术」按钮，点击做前端过滤（静态站无需请求）。
- 涉及文件：`source/js/home-tabs.js`（新建）、`source/_data/styles.styl`。

### P1-1 本地搜索（改动量：小）

- 做法：安装 `hexo-generator-searchdb`，在 `_config.next.yml` 开启 `local_search.enable: true`，导航条搜索框复用 NexT 内置搜索弹层。
- 价值：内容超过 20 篇个股页 + 报告页后，搜索是唯一可靠的到达路径。

### P1-2 股票池总览数据（改动量：中）

- 做法：扩展 `tools/stockdb/export_json.py`（或新建 `export_overview.py`），从 PostgreSQL 汇总输出 `source/stocks/data/overview.json`：

```json
{
  "updated": "2026-09-20",
  "stocks": [
    { "name": "贵州茅台", "slug": "guizhou-maotai", "close": 1502.3,
      "pe_ttm": 21.4, "pe_pct10": 12, "pb": 7.1, "pb_pct10": 20,
      "dv_ttm": 3.5, "score": 78 }
  ]
}
```

- 由 `run_daily.py` 每日跟随行情一起刷新，同时供 P0-1 下拉菜单、P0-2 右栏、P1-3 个股导航条复用，**一处生成、三处消费**。

### P1-3 个股页横向股票导航（改动量：小）

- 做法：新建 `source/js/stock-nav.js`，读 `overview.json` 在个股页顶部生成 11 个 chip（茅台 伊利 美的 … 药明康德），当前股票高亮，横向可滚动。
- 价值：CSDN 专栏也有横向切换，解决「看完茅台想看宁德要退回分类页」的问题。

### P1-4 文章页右侧目录 + 相关阅读（改动量：中）

- 做法：
  1. `styles.styl` 覆盖 `.post-toc`，≥1200px 时固定在右侧（`position: sticky`），长文（如 9000 字读书笔记）体验提升明显。
  2. 相关阅读：装 `hexo-related-posts` 或用 `scripts/` 自写生成器，在正文底部输出「同分类 / 同标签的 3 篇」。
- 注意：TOC 右移后需确认与首页右栏、左栏折叠不冲突，仅在 `post` 布局生效。

### P2-1 阅读量统计（改动量：小）
`busuanzi_count.enable: true`，卡片与页脚显示阅读量。依赖外部统计服务，若网络不可达则降级不显示（不影响布局）。

### P2-2 卡片封面图（改动量：小）
front-matter 增加 `cover:`，首页卡片右侧 120×80 缩略图；投资类文章可复用估值图表截图。

### P2-3 移动端底部导航（改动量：中）
≤991px 显示底部 Tab（首页 / 个股 / 三好 / 关于），隐藏左栏折叠把手。

### P2-4 深色模式手动切换（改动量：小）
当前 `darkmode: true` 跟随系统；在导航条加切换按钮并写入 localStorage。

## 四、实施路线

**第一期 · 骨架与信息密度**：P0-1 吸顶导航条 → P0-2 右栏（先做三好评分榜，数据现成）→ P0-3 卡片密度 → P0-4 频道 Tab。
做完这一期，首页就从「单栏流水」变成 CSDN 式的三栏门户，右侧不再是空白。

**第二期 · 内容可达性**：P1-2 生成 overview.json → P1-1 搜索 → P1-3 个股横向导航 → 反向填充 P0-1 下拉与 P0-2 速览模块。
第二期把「数据资产上首页」闭环，也是本站区别于普通博客的关键。

**第三期 · 体验打磨**：P1-4 目录与相关阅读 → P2 各项。

每期结束按既有流程验证与部署：

```bash
./node_modules/.bin/hexo clean && ./node_modules/.bin/hexo generate
# 本地 4001 端口起服务 + 无头截图确认（≥1200px 三栏、992–1199px 两栏、<992px 单列）
# 双分支：source 提交源码；.deploy_git 推 main（--force）
```

## 五、约束与风险

1. **不碰主题模板**：所有改动通过 `custom_file_path` 注入、`styles.styl` 覆盖、`scripts/` 钩子、`source/js/` 前端脚本实现，主题升级不受影响。
2. **全宽改造已存在**：`styles.styl` 已把 `.main` / `.footer-inner` 在 ≥1200px 统一为 `calc(100% - 20px)`，新增 Grid 时需确认页脚宽度同步，避免右栏与页脚错位。
3. **JS 注入的取舍**：右栏、Tab、个股导航为前端注入，无 JS 时降级为现有布局（不报错、不塌陷），但建议右栏内容同时保留 `/stocks/`、`/three-good/` 等静态入口页，兼顾 SEO。
4. **品牌一致性**：沿用 `--brand-color: #1b4d3e` 系列变量（亮/暗双套已定义），新增模块直接引用变量，不写死颜色。
5. **数据时效**：右栏速览依赖每日 16:10 的 `CLIVIA-StockDaily` 任务；overview.json 必须接入 `run_daily.py`，否则会出现「导航条有股票、数据停在旧日期」。
