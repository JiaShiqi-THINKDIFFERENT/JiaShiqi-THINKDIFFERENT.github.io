## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 601816.SH |
| 申万一级行业 | 交通运输 |
| 细分领域 | 高铁运营 |
| 主营业务 | 京沪高速铁路的运营与资产管理，收入来自票价与跨线列车使用费 |

## 投资逻辑

- 一句话逻辑：独占京沪黄金通道的高铁资产，客流刚性、现金流类公用事业。
- 核心竞争力：京沪高铁是不可复制的线位资产，客流随商务与出行需求自然增长，成本端刚性较低。
- 主要风险：票价浮动上限仍受管制，缺乏完全自主定价权；分流线路与商务出行景气直接影响客流。
