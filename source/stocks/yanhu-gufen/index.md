# 盐湖股份（000792.SZ）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 000792.SZ |
| 申万一级行业 | 基础化工 |
| 细分领域 | 钾肥与锂盐 |
| 主营业务 | 察尔汗盐湖氯化钾、碳酸锂的开采与加工，是国内最大的钾肥生产基地 |

## 投资逻辑

- 一句话逻辑：察尔汗盐湖资源不可复制，钾肥提供现金流底盘，碳酸锂提供第二增长曲线。
- 核心竞争力：独家掌握察尔汗盐湖采矿权，钾肥国内产能第一，提锂成本处于行业最低区间；资源禀赋构成天然壁垒。
- 主要风险：氯化钾与碳酸锂价格均为全球定价、公司完全被动接受，周期下行时利润大幅波动；历史上有破产重整记录，治理信任度偏低。
