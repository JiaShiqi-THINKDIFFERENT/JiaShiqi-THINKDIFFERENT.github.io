# 中国中免（601888.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 601888.SH |
| 申万一级行业 | 社会服务 |
| 细分领域 | 免税零售 |
| 主营业务 | 口岸、离岛与市内免税店运营，全球最大免税运营商之一 |

## 投资逻辑

- 一句话逻辑：免税牌照稀缺 + 离岛政策红利，长期受益于消费回流。
- 核心竞争力：全牌照（口岸、离岛、市内、机上）运营能力，海南离岛免税市场份额领先，供应链与议价能力强。
- 主要风险：免税牌照存在放开可能，竞争或加剧；核心变量是消费景气与海南客流、政策调整。
