# 中国船舶（600150.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600150.SH |
| 申万一级行业 | 国防军工 |
| 细分领域 | 船舶制造 |
| 主营业务 | 军民船建造、修船与海工装备，旗下江南造船、外高桥造船等核心船厂 |

## 投资逻辑

- 一句话逻辑：造船上行周期叠加国企整合，手持订单锁定未来数年业绩。
- 核心竞争力：旗下江南造船、外高桥造船等核心船厂，军民船并进，高价订单逐步进入交付与结算期。
- 主要风险：造船交付周期长、钢材成本波动需跨期消化；汇率与订单撤销风险，周期高位订单持续性存疑。
