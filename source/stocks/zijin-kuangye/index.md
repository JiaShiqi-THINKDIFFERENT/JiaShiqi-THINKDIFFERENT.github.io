# 紫金矿业（601899.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 601899.SH |
| 申万一级行业 | 有色金属 |
| 细分领域 | 铜 / 金 / 锂全球化矿产资源开发 |
| 主营业务 | 铜、金、锌、锂等矿产资源的勘查、开发、冶炼与销售（卡莫阿、巨龙、Timok 等世界级矿山） |

## 投资逻辑

- 一句话逻辑：逆周期并购 + 低成本运营的全球化矿业龙头，靠资源禀赋与产量增长穿越铜金价格周期
- 核心竞争力：世界级矿山资源储备稀缺、并购估值纪律与开发执行力强（"矿石流五环归一"工程化管理）、铜金双品种对冲
- 主要风险：铜金为全球定价大宗商品、公司无定价权，盈利随宏观与美元利率剧烈波动；海外矿权面临资源国政策与地缘政治风险；并购带来的高负债与减值压力
