## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 000988.SZ |
| 申万一级行业 | 机械设备 |
| 细分领域 | 激光装备与光通信 |
| 主营业务 | 激光加工装备、传感器与光通信模块，激光装备出口与 AI 光模块是两大增长点 |

## 投资逻辑

- 一句话逻辑：激光装备基本盘 + AI 光模块弹性，两条线都在各自赛道里处于国产第一梯队。
- 核心竞争力：激光加工装备国内龙头之一，传感与光模块业务切入高速光互联，客户覆盖主流设备商；高校背景带来持续技术供给。
- 主要风险：激光设备行业价格竞争激烈、毛利率承压；光模块受海外客户资本开支节奏影响，需求波动大。
