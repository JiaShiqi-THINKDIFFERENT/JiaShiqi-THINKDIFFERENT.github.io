## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600309.SH |
| 申万一级行业 | 基础化工 |
| 细分领域 | 聚氨酯与新材料 |
| 主营业务 | MDI、TDI 等聚氨酯产品、石化与精细化学品的研发生产，MDI 全球龙头 |

## 投资逻辑

- 一句话逻辑：全球 MDI 寡头之一，成本曲线最左端 + 持续扩张的新材料平台。
- 核心竞争力：MDI 技术与一体化成本优势难以复制，全球产能布局完善，石化与精细化学品提供第二支柱。
- 主要风险：MDI 价格受供需与原油成本双向影响，周期性明显；海外产能扩张带来地缘与贸易摩擦风险。
