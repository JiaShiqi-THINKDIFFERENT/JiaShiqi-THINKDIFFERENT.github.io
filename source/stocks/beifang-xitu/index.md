## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600111.SH |
| 申万一级行业 | 有色金属 |
| 细分领域 | 稀土冶炼分离 |
| 主营业务 | 轻稀土冶炼分离与功能材料，拥有白云鄂博矿资源与冶炼配额优势 |

## 投资逻辑

- 一句话逻辑：稀土配额与资源双垄断，新能源与军工需求打开长期空间。
- 核心竞争力：独家掌握白云鄂博矿资源与绝大部分轻稀土冶炼分离配额，稀土是不可再生的战略资源，准入壁垒极高。
- 主要风险：稀土价格受配额政策与市场供需双重影响，虽非完全被动但缺乏自由定价权；下游需求景气波动大。
