## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 601857.SH |
| 申万一级行业 | 石油石化 |
| 细分领域 | 油气一体化 |
| 主营业务 | 原油天然气勘探开发、炼油化工与成品油销售，上下游一体化布局 |

## 投资逻辑

- 一句话逻辑：上下游一体化削弱油价波动，资源与管网构成长期壁垒。
- 核心竞争力：上游储量与产量国内领先，管网与炼化销售网络完备，一体化结构使公司比纯上游更能穿越油价周期。
- 主要风险：原油价格完全外生，炼化景气随宏观与新能源替代波动；税费与价格管制影响终端盈利。
