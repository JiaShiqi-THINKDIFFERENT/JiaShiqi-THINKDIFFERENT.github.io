# 长江电力（600900.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600900.SH |
| 申万一级行业 | 公用事业 |
| 细分领域 | 水电（全球最大水电上市公司） |
| 主营业务 | 三峡、溪洛渡、向家坝、乌东德、白鹤滩六座巨型梯级电站的水力发电与售电 |

## 投资逻辑

- 一句话逻辑：不可复制的巨型水电资产 + 明确分红承诺，现金流稳定到接近"类债券"，是组合中的压舱石
- 核心竞争力：优质大型水电资源独占、六库联调提升发电效率、零燃料成本且优先消纳、财务费用随还本付息持续下降
- 主要风险：电价受政府管制无自主提价权、来水丰枯直接影响发电量、成长只能依赖资产注入，利率上行时类债券资产的估值吸引力下降
