# 中国神华（601088.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 601088.SH |
| 申万一级行业 | 煤炭 |
| 细分领域 | 煤炭与煤电一体化 |
| 主营业务 | 煤炭生产销售，配套自有铁路、港口、航运与煤电，长协煤比例高 |

## 投资逻辑

- 一句话逻辑：煤电路港航一体化，长协机制下现金流稳定，类债券属性的高股息标的。
- 核心竞争力：煤炭资源禀赋优、开采成本低，自有铁路港口航运降低全链成本，长协煤占比高使盈利波动远小于同业。
- 主要风险：煤价仍随周期波动，电价市场化带来煤电利润不确定性；安全生产与双碳约束影响长期资本开支节奏。
