# 北方华创（002371.SZ）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 002371.SZ |
| 申万一级行业 | 电子 |
| 细分领域 | 半导体设备（国产替代最核心的平台化龙头） |
| 主营业务 | 刻蚀、薄膜沉积（PVD/CVD/ALD）、清洗、炉管等半导体装备，以及精密电子元器件 |

## 投资逻辑

- 一句话逻辑：国内唯一覆盖"刻蚀 + 薄膜 + 清洗 + 炉管"的平台型半导体设备商，是晶圆厂产能扩张与国产替代的双重受益标的
- 核心竞争力：工艺 Know-how 与产线验证周期构筑极高壁垒、平台化供货提升单机价值量、国内稀缺供给带来议价能力
- 主要风险：晶圆厂扩产节奏的周期性波动、美国出口管制对零部件与先进制程设备的约束、高研发投入与股权激励费用阶段性压制利润率
