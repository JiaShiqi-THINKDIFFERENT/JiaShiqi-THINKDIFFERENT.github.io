## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600406.SH |
| 申万一级行业 | 电力设备 |
| 细分领域 | 电网自动化 |
| 主营业务 | 电网调度自动化、继电保护、特高压与电力信息化的设备与系统集成 |

## 投资逻辑

- 一句话逻辑：电网自动化核心供应商，电网投资与特高压建设直接受益。
- 核心竞争力：背靠国网体系，在调度自动化、继保护与特高压控制保护领域份额领先，准入壁垒与粘性极高。
- 主要风险：客户单一（电网集采），议价能力受限；电网投资节奏由政策决定，应收账款回收周期长。
