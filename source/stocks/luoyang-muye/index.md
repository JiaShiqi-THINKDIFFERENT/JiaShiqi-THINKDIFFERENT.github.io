## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 603993.SH |
| 申万一级行业 | 有色金属 |
| 细分领域 | 铜钴钼钨采选冶 |
| 主营业务 | 刚果金铜钴、国内钼钨等矿产的采选冶炼，国际化矿业运营平台 |

## 投资逻辑

- 一句话逻辑：国际化矿业平台，铜钴资源位于全球成本曲线左侧。
- 核心竞争力：刚果金铜钴矿储量大、品位高，国内钼钨资源配套，民营机制灵活、运营效率较高。
- 主要风险：金属价格完全由全球供需决定，无议价权；海外矿山面临地缘、税收与社区风险。
