## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 300308.SZ |
| 申万一级行业 | 通信 |
| 细分领域 | 光模块 / 光器件（全球高速光模块第一梯队） |
| 主营业务 | 100G—1.6T 高速光通信收发模块的研发、生产与销售，配套数据中心与电信网络 |

## 投资逻辑

- 一句话逻辑：AI 算力网络的"血管"，800G / 1.6T 高速光模块全球出货领先，业绩直接绑定北美云厂商的 AI 资本开支周期
- 核心竞争力：速率迭代的先发量产能力（硅光、CPO 提前卡位）、头部云厂商长周期认证带来的份额粘性、海外产能（泰国等）对冲关税与供应链风险
- 主要风险：下游客户高度集中（单一大客户占比高）议价权偏弱、云厂商资本开支节奏波动、速率升级导致产品生命周期缩短与逐年降价、出口管制等地缘扰动
