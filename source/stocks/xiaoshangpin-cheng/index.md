# 小商品城（600415.SH）

## 基本信息

| 项目 | 内容 |
| ---- | ---- |
| 股票代码 | 600415.SH |
| 申万一级行业 | 商贸零售 |
| 细分领域 | 专业市场运营 + 跨境 B2B |
| 主营业务 | 义乌国际商贸城等市场的商铺租赁与市场服务费、Chinagoods 跨境 B2B 平台、义支付（Yiwu Pay）跨境人民币支付、贸易服务 |

## 投资逻辑

- 一句话逻辑：全球最大小商品集散地的唯一运营主体，靠不可复制的区位与商户网络收租，再把线下流量搬到 Chinagoods + 跨境支付做第二曲线
- 核心竞争力：义乌市场独家运营权、几十年集聚的供应链与商户黏性、租金可随市场景气上调、跨境人民币支付牌照稀缺
- 主要风险：外贸出口景气与关税环境强相关、Chinagoods 货币化仍在早期、海外分市场（迪拜等）爬坡不及预期、国资体制下新业务推进节奏偏慢
